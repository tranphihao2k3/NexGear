Aggregation Pipeline — Thống kê thực tế

📊 Doanh thu theo tháng
db.orders.aggregate([ { $match: { status: "delivered", "payment.status": "paid" }}, { $group: { _id: { year: { $year: "$createdAt" }, month: { $month: "$createdAt" } }, revenue: { $sum: "$total" }, orderCount:{ $sum: 1 }, avgOrder: { $avg: "$total" }, // Online vs POS split onlineRev: { $sum: { $cond: [{ $eq:["$channel","online"]},"$total",0] }} }}, { $sort: { "_id.year": 1, "_id.month": 1 }} ])
📦 Sản phẩm sắp hết hàng
db.products.aggregate([ { $match: { isActive: true, $expr: { $lte: [ "$stock", "$lowStockAlert" ]} }}, { $lookup: { from: "inventory_logs", let: { pid: "$_id" }, pipeline: [ { $match: { $expr: { $and: [ { $eq: ["$product", "$$pid"] }, { $eq: ["$type", "import"] } ] }}}, { $sort: { createdAt: -1 }}, { $limit: 1 } ], as: "lastImport" }}, { $sort: { stock: 1 }} ])
07 — Organization

Team Roles & Phân Quyền Hệ Thống

4 roles được thiết kế cho team 2–5 người. Một người có thể đảm nhiệm nhiều roles.

ADMIN
Chủ shop / Founder
  • ✅ Toàn quyền trên mọi tính năng
  • ✅ Xem costPrice và lợi nhuận thực
  • ✅ Quản lý nhân viên, phân quyền
  • ✅ Xóa đơn hàng, hoàn tiền
  • ✅ Cài đặt hệ thống, tích hợp payment
  • ✅ Export toàn bộ dữ liệu
  • ✅ Xem báo cáo P&L đầy đủ
MANAGER
Quản lý / Trưởng nhóm
  • ✅ Quản lý đơn hàng (mọi trạng thái)
  • ✅ Nhập kho, điều chỉnh tồn
  • ✅ Tạo/sửa sản phẩm và danh mục
  • ✅ Tạo mã giảm giá, flash sale
  • ✅ Xem báo cáo doanh thu (không xem costPrice)
  • ❌ Không xóa dữ liệu vĩnh viễn
  • ❌ Không cài đặt payment gateway
STAFF
Nhân viên bán hàng
  • ✅ Xử lý đơn hàng (confirm, pack, ship)
  • ✅ Xem tồn kho (không chỉnh)
  • ✅ Chat/liên hệ khách hàng
  • ✅ Thêm ghi chú staff vào đơn
  • ❌ Không xem báo cáo tài chính
  • ❌ Không sửa giá, không tạo SP mới
  • ❌ Không truy cập admin dashboard đầy đủ
CASHIER
Thu ngân (POS only)
  • ✅ Truy cập màn hình POS
  • ✅ Tạo đơn hàng offline tại quầy
  • ✅ Tìm kiếm sản phẩm, quét barcode
  • ✅ Xử lý thanh toán tiền mặt / chuyển khoản
  • ✅ In hóa đơn
  • ❌ Không truy cập admin dashboard
  • ❌ Không xem đơn online

08 — Features

Danh Sách Tính Năng Đầy Đủ

🛍️ CUSTOMER EXPERIENCE

🔍 Search & Filter — Full-text search, filter theo danh mục / thương hiệu / giá / switch type / kết nối / màu sắc. Sort: mới nhất, bán chạy, giá tăng/giảm.

🛒 Cart & Checkout — Guest checkout không cần tài khoản. Save địa chỉ nhiều nơi. Áp mã giảm giá. Tính phí ship tự động theo GHN API.

💳 Thanh toán đa kênh — VNPay (QR, ATM, thẻ), chuyển khoản ngân hàng, COD. Xác nhận tự động qua webhook.

📦 Order Tracking — Timeline theo dõi đơn hàng chi tiết. Tích hợp tracking GHN để xem tình trạng vận chuyển thực tế.

🔔 Notifications — Gửi email + Zalo OA tự động: xác nhận đơn, đóng gói xong, đang giao, đã giao.

⭐ Review System — Chỉ user đã nhận hàng mới review được (isVerified). Upload ảnh thực tế. Pros/Cons. Admin duyệt trước khi hiển thị.

❤️ Wishlist & Compare — Lưu yêu thích. So sánh specs tối đa 3 sản phẩm cùng danh mục side-by-side.

👤 User Account — Lịch sử mua hàng, quản lý địa chỉ, đổi mật khẩu, loyalty points (tùy chọn).

⚙️ OPERATIONS & ADMIN

📊 Dashboard Tổng quan — KPIs: doanh thu, số đơn, AOV, lợi nhuận. Charts: doanh thu theo ngày/tuần/tháng, online vs offline, kênh thanh toán.

📦 Quản lý Kho — Nhập hàng từ nhà cung cấp. Điều chỉnh tồn (hư hỏng, kiểm kê). Cảnh báo sắp hết. Lịch sử xuất nhập đầy đủ.

🚚 Xử lý Đơn hàng — Cập nhật trạng thái hàng loạt. In phiếu giao hàng (A5). Tạo vận đơn GHN/GHTK tự động. Ghi chú nội bộ.

💰 Quản lý Tài chính — Ghi nhận chi phí (nhập hàng, lương, mặt bằng, marketing). Báo cáo P&L theo tháng. Export Excel.

🎁 Khuyến mãi — Tạo mã giảm giá (%). Flash sale có giờ kết thúc. Banner trang chủ. Hiển thị sản phẩm featured.

🖥️ POS Offline — Giao diện bán tại quầy. Quét barcode. Thanh toán tiền mặt/chuyển khoản/QR. In hóa đơn. Sync tồn kho ngay.

👥 Quản lý Khách hàng — Lịch sử mua, total spent, hạng VIP. Ghi chú CRM. Tìm kiếm + filter khách.

📋 Báo cáo xuất Excel — Doanh thu, đơn hàng, tồn kho, lịch sử giao dịch. Sẵn sàng nộp kế toán.
