08 — Motion

Animation & Micro-interactions

Tất cả animation cần subtle, nhanh (≤300ms), purposeful. Không dùng animation chỉ để "đẹp" mà không có mục đích.

PAGE TRANSITIONS

Fade + Slide Up

Khi navigate trang mới: fade in + translateY(12px → 0), duration 200ms, ease-out. Dùng Framer Motion AnimatePresence.

initial: { opacity: 0, y: 12 }
animate: { opacity: 1, y: 0 }
duration: 0.2s, ease-out
STAGGER REVEAL

Product Grid Load

Khi load product list: mỗi card fade in với delay stagger 50ms. Card 1 → 50ms → Card 2 → 50ms → ... Tạo hiệu ứng cascade.

staggerChildren: 0.05s
delayChildren: 0.1s
Per card: opacity 0→1, y 8→0
HOVER STATES

Card & Button Hover

Product card: translateY(-2px) + box-shadow nổi lên, 180ms ease. Button hover: background change 150ms. Icon button: bg fill 150ms.

card:hover
transform: translateY(-2px)
box-shadow: 0 8px 28px ...
transition: 180ms ease
SKELETON LOADING

Skeleton Pulse

Trước khi data load: Skeleton placeholder với animation shimmer ngang, màu #E4E1D8 → #ECEAE3 → #E4E1D8, duration 1.5s infinite.

ADD TO CART

Cart Bounce Animation

Khi "Thêm vào giỏ": icon 🛒 trong nav bounce scale(1→1.3→1) 300ms. Counter badge pop in scale(0→1) 200ms. Button: checkmark momentary.

TOAST NOTIFICATION

Slide In từ phải

Toast xuất hiện từ góc dưới phải: slide in từ X+80→0, fade in, duration 250ms. Auto dismiss sau 3s với progress bar. Stack tối đa 3 toast.

Breakpoints & Responsive Rules

768px

1024px

1024–1279PX

3 cột. Full nav. Filter sidebar dọc. Product grid: 3 cột. 2-column checkout layout.

1280px

Desktop L

1280PX+

Max-width 1200px centered. 4 cột product grid. Full sidebar filter. Hero 2-col. Tất cả features đầy đủ.

Quy tắc responsive cụ thể

  • Nav: Desktop = full links. Tablet = ẩn bớt link phụ. Mobile = hamburger icon → slide-in menu từ phải
  • Product grid: Desktop 4 cột → Tablet 2 cột → Mobile 1 cột (hoặc 2 cột compact)
  • Product detail: Desktop side-by-side (gallery | info). Mobile = gallery trên, info dưới. "Mua ngay" sticky bottom bar mobile.
  • Filter: Desktop = sidebar dọc luôn hiện. Tablet/Mobile = nút "BỘ LỌC" → bottom sheet hoặc fullscreen overlay
  • Checkout stepper: Desktop 3 bước horizontal. Mobile = chỉ hiện step hiện tại + số bước
  • Font size: KHÔNG scale down dưới 12px. Hero H1 dùng clamp(36px, 8vw, 96px)
  • Touch targets: Tất cả button/link ≥ 44×44px trên mobile (Apple HIG)
  • Admin dashboard: Chỉ tối ưu cho tablet (1024px+). Mobile có thể xem basic nhưng không ưu tiên
  • POS: Tối ưu cho tablet 10–12 inch landscape. Cần test thực tế trên iPad
  • Image: Dùng next/image với sizes prop. Lazy load tất cả ảnh dưới fold

  • Tạo Color Styles đầy đủ 14 màu
  • Tạo Text Styles cho tất cả 9 type scale
  • Tạo Effect Styles: shadow-sm, shadow-md, shadow-lg, glow-cyan
  • Tạo Grid Style: 12-col grid (1200px max-width, 32px padding, 16px gap)
  • Tổ chức Pages: Design System / Homepage / Product Pages / Cart-Checkout / Account / Admin / Mobile
  • Đặt tên layer rõ ràng (không để "Rectangle 47")

✦ COMPONENTS

  • Component: Button — 6 variants × 4 sizes × 4 states (default/hover/disabled/loading)
  • Component: Input — 4 states (default/focus/error/success) + icon variant
  • Component: Product Card — 3 variants (standard/sale/out-of-stock)
  • Component: Badge — tất cả màu và status
  • Component: Navigation Bar — desktop + mobile
  • Component: Alert/Toast — 4 types
  • Component: Modal — confirm + form
  • Component: Pagination, Breadcrumb, Stepper

✦ PAGES

  • 16 trang khách hàng — Desktop 1440px frame
  • 16 trang khách hàng — Mobile 390px frame

  • POS Interface — Tablet 1024×768 frame
  • 404 page + Empty states (giỏ hàng rỗng, wishlist rỗng, no search results)
  • Loading/skeleton states cho tất cả data sections

✦ HANDOFF QA

  • Tất cả text dùng đúng font: Orbitron / DM Sans / JetBrains Mono
  • Màu sắc đúng với Color Styles (không hard-code hex lẻ)
  • Spacing đều theo 8px grid (dùng Dev Mode để check)
  • Không có layer nào chưa đặt tên hoặc group chưa đặt tên
  • Kiểm tra contrast ratio ≥ 4.5:1 cho tất cả text nhỏ (WCAG AA)
  • Export assets: SVG icons + PNG 2x cho tất cả ảnh cần
  • Prototype flow: Trang chủ → Product list → Product detail → Cart → Checkout → Success
